# dilbert

Explains a pull request, branch, commit range, or uncommitted diff as a document
someone non-technical can actually follow — while staying complete enough to review
the change from.

See [`skills/dilbert/SKILL.md`](./skills/dilbert/SKILL.md) for the full skill.

```
/plugin marketplace add SYKhayyat/claude-skills
/plugin install dilbert@claude-skills
```

PR mode needs the `gh` CLI, authenticated; branch, commit-range and working-tree
modes need only `git`. See [docs/ONBOARDING.md](../docs/ONBOARDING.md) and
[docs/TROUBLESHOOTING.md](../docs/TROUBLESHOOTING.md).
